# MindCare - Mental Health Support App

A modern Streamlit-based web application designed to support mental health awareness and self-assessment for students, lecturers, and staff.

## Features
- **User Authentication**: Secure register and login system.
- **Mental Health Assessment**: Guided questionnaire with tailored emotional insights.
- **Modern UI**: Dark-themed custom interface with responsive layout.

## Run Locally / Clone from GitHub

### Linux / macOS / GitHub Codespaces (One-liner):
```bash
git clone <YOUR-GITHUB-REPO-URL> && cd mental-health-support && python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt && streamlit run app.py
```

### Windows PowerShell (One-liner):
```powershell
git clone <YOUR-GITHUB-REPO-URL>; cd mental-health-support; python -m venv venv; .\venv\Scripts\activate; pip install -r requirements.txt; streamlit run app.py
```
